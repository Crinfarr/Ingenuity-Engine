# The Ingenuity Engine
### A game server, card runtime, and partial rules engine for Magic: The Gathering
---
Before asking any questions, **READ ME**
> ### This is not a full stack. In order to use The Ingenuity Engine, you'll need to write or download your own frontend.
The intent of The Ingenuity Engine is to act as a platform-agnostic server to play MTG on. As long as a frontend supports the spec, *any* other frontend will be able to crossplay with it.

If you intend to write your own frontend, check [Protocol.md](./PROTOCOL.md) for notes on used formats and libraries

If you intend to run a server, check [THIS_FILE_IS_NOT_WRITTEN_YET.md]()
